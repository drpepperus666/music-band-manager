## 4. Административная панель

- Суперпользователь `admin` создан (`createsuperuser`), вход —
  `/admin/`; тестовая группа «Bandly Operators» (view/add/change
  групп без delete) и пользователь `operator` (is_staff, без
  superuser) — для проверки разграничения доступа.
- `BandAdmin`: `list_display` (id, название, инструмент, активность,
  вычисляемое число активных репетиций, ссылка на сайт),
  `list_display_links = ("name",)`, `list_editable = ("is_active",)`,
  `search_fields` (название, инструмент), `list_filter`,
  `ordering`, `list_per_page = 20`, `readonly_fields = ("id",)`,
  inline участников и репетиций (`extra = 0`, у репетиций
  `can_delete = False`), `view_on_site = True`.
- `MemberAdmin`: столбцы (включая вычисляемое `is_experienced`),
  поиск по инструменту/статусу/группе, фильтр, сортировка по стажу,
  редактирование стажа из списка.
- `RehearsalAdmin`: столбец инструмента группы (метод + `ordering`
  по связанному полю), поиск `band__name`, фильтры дата/статус,
  `list_select_related = ("band",)`, `date_hierarchy`,
  `autocomplete_fields = ("band",)`, действия «Отменить выбранные
  репетиции» (через `cancel()`) и «Вернуть в активные» (`update`).
- Локализация: `AppConfig.verbose_name` («Группы», «Участники»,
  «Репетиции»), русские `verbose_name` моделей/полей,
  `help_text` у подсказок.

## 5. Модели, миграции, менеджер QuerySet

- `Rehearsal.status` — `TextChoices` (active/cancelled/completed)
  вместо `is_cancelled`: миграции `0002` (поле), `0003` (данные
  RunPython), `0004` (удаление старого поля). `cancel()` переводит
  в `cancelled` без удаления записи.
- `RehearsalQuerySet` (`active/cancelled/completed/for_date`) +
  `RehearsalManager`; представления используют
  `Rehearsal.objects.active()`; `all()` по-прежнему возвращает всё
  (история для статистики сохраняется).
- `Member.is_experienced` — `GeneratedField` (`experience_years >= 3`,
  `db_persist=True`).
- `Band.slug` — `SlugField(unique)` из транслитерации + `pk`
  (миграция данных `0003_populate_slugs`, автосоздание в `save()`);
  деталка — `<slug:slug>/`; `get_absolute_url()` + `reverse`;
  ссылки в шаблонах и «Посмотреть на сайте» в админке.
- Контекстный процессор `band_context` (`site_name`, `bands_count`),
  счётчик групп в навигации всех страниц.

## 6. ORM-запросы, фильтрация, сортировка, пагинация, статистика

Список репетиций: `active()` → фильтры даты/группы/поиска (`Q`,
`icontains`) → белый список сортировки → `annotate(F)` + `values`
→ `order_by(sort, id)` → `Paginator` по 5 + `{% querystring %}`.
Свободные группы: `active().filter(дата)` → `values_list` →
`exclude`. Деталки: `get_object_or_404` (+ `select_related`).
Статистика: итоги `aggregate(Count(filter=Q(status=...)))` и
группировка от `Band` с условным `Count` (группы без репетиций
дают 0).

## 7. Доступность с учётом статусов

Группа считается занятой только при активной репетиции на дату:
проверено на 2026-09-15 (Nirvana занята, Beatles свободна);
после перевода тестовой репетиции в `cancelled`/`completed`
группа снова свободна; статистика считает каждое состояние
отдельно.
