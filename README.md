# Система организации музыкальных групп

## Назначение
Консольное приложение предназначено для упрощения процесса управления музыкальным коллективом. Оно решает задачи планирования репетиций, отбора новых музыкантов и справедливого распределения затрат на аренду студий.

## Целевая аудитория
Музыканты, лидеры и основатели музыкальных групп, а также менеджеры начинающих музыкальных коллективов.

## Предметная область
Музыкальная индустрия, организация репетиционного процесса и базовый менеджмент музыкальных коллективов.

## Основные сущности
- Группа
- Участник
- Инструмент
- Репетиция

## Основные функции
- **Оценка кандидата на вступление в группу**: функция сравнивает инструмент, на котором играет кандидат (строка), с инструментом, который сейчас требуется группе (строка), а также проверяет его опыт игры в годах (число). С помощью конструкции `if-else` возвращается вердикт — подходит музыкант для прослушивания или нет.
- **Расчет стоимости репетиции для одного участника**: функция принимает общую стоимость аренды студии (число), количество участников на репетиции (число) и статус наличия скидки у группы (логический тип `bool`). С помощью математических операций и ветвлений высчитывается итоговая сумма, которую должен сдать каждый пришедший музыкант.
- **Проверка пригодности репетиционного помещения**: функция принимает вместимость студии (число), размер группы (число) и флаг наличия у группы собственного крупногабаритного оборудования, например барабанов (логический тип `bool`). На основе условий (`if-elif-else`) возвращается текстовый статус, поместится ли группа в зал или требуется найти студию побольше.
