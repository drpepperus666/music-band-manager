# Система организации музыкальных групп

## Назначение
Консольное приложение для управления музыкальным коллективом: учёт групп, оценка кандидатов, планирование репетиций и управление бронированиями.

## Целевая аудитория
Музыканты, лидеры и основатели музыкальных групп, а также менеджеры начинающих музыкальных коллективов.

## Предметная область
Музыкальная индустрия, организация репетиционного процесса и базовый менеджмент музыкальных коллективов.

## Основные сущности
- Группа (Band)
- Участник/Кандидат (Member)
- Репетиция (Rehearsal)

## Основные функции
- **Оценка кандидата на вступление в группу**: функция сравнивает инструмент кандидата с требуемым инструментом группы и проверяет опыт в годах. Возвращает вердикт — подходит кандидат или нет.
- **Расчет стоимости репетиции для одного участника**: функция принимает общую стоимость аренды студии, количество участников и наличие скидки. Высчитывает итоговую сумму с каждого участника.
- **Проверка пригодности репетиционного помещения**: функция принимает вместимость студии, размер группы и флаг наличия крупного оборудования. Возвращает статус пригодности помещения.

## Структура проекта
- `main.py` — точка запуска приложения и меню
- `bands.py` — функции управления группами (добавление, поиск, фильтрация, оценка кандидата)
- `rehearsals.py` — функции управления репетициями (бронирование, отмена, проверка доступности)
- `storage.py` — загрузка и сохранение данных в JSON-файлах
- `utils.py` — вспомогательные функции ввода с обработкой ошибок
- `data/` — JSON-файлы данных (`bands.json`, `members.json`, `rehearsals.json`)
- `tests/` — автоматизированные тесты (`test_bands.py`, `test_rehearsals.py`)
- `README.md` — документация проекта
- `requirements.txt` — зависимости проекта

## Формат хранения данных
Данные хранятся в JSON-файлах:
- `data/bands.json` — список групп со структурой: `id`, `name`, `foundation_date`, `required_instrument`, `is_active`
- `data/members.json` — список кандидатов: `id`, `band_id`, `instrument`, `experience_years`, `status`
- `data/rehearsals.json` — список репетиций: `id`, `band_id`, `rehearsal_date`, `participants`

Данные загружаются при запуске приложения и сохраняются при выходе.
